# Dataset

Place the Jigsaw competition files downloaded from Kaggle in this folder.

Expected training file:

- `train.csv`

The original Jigsaw training file contains `comment_text` plus six binary labels:
`toxic`, `severe_toxic`, `obscene`, `threat`, `insult`, and `identity_hate`.

The dataset is intentionally not included in this GitHub repository. Download it from the official Kaggle competition page using your own Kaggle account and permissions.
